# 后台功能盘点与待办

> 盘点日期：2026-09-24；2026-09-25 后台改用 shadcn-admin 重建，文中的文件路径和状态已随之更新。范围是 `web/src`、`internal/api` 与当前本地后台的只读页面观察；没有在真实站点上执行保存、删除或发布。本文是可执行待办，不把代码推断写成已复现的故障。整体里程碑与占位功能归属仍以 [roadmap.md](roadmap.md) 为准。

## 1. 当前可用范围

| 区域 | 已有能力 | 主要缺口 |
|---|---|---|
| 仪表盘 | 内容数量、每月发布趋势、最新文章、待发布改动、常用标签、快捷入口 | 评论、访问、RSS 订阅、存储和备份还没有实现，界面上不再显示占位；部分请求失败时只会持续显示骨架或空值 |
| 文章与页面 | 创建、列表筛选/搜索/分页、编辑、删除与回收站、批量发布/删除/恢复、Git 发布 | 只读部署仍显示写入口（A04） |
| 编辑器 | 可视化与 Markdown 源码、服务端预览、图片上传、冲突提示 | 冲突对比缺少基线版本；手机宽度没有预览入口；上传后的文件缺少管理界面 |
| 分类法 | 查看词条、按词条进入内容列表 | 没有跨文章重命名或合并词条；词条本身从内容推导，不宜做独立 CRUD |
| 主题与设置 | 当前主题的 schema 表单、站点基本设置、界面语言与外观 | 无主题安装/切换；设置缺少未保存提醒和并发修改保护；内置主题字段说明仍是英文 |
| 系统 | 单账号登录、安装引导、发布状态 | 评论、附件库、菜单、插件、用户、备份入口尚未实现；只读服务器仍展示可写操作 |

## 4. 占位入口与后续阶段

这些不是 v1.0 主流程的缺陷，按 [roadmap.md §6](roadmap.md#6-后台占位功能的归属) 推进。原来的灰色占位入口已从界面移除，实现后再加回；没有真实数据来源时不显示编造的数字。

| 功能 | 建议范围与前置决策 | 阶段 |
|---|---|---|
| 菜单、主题安装/切换 | 定义 `kite.yaml` 菜单与主题契约；实现主题列表、安装、验证、预览和回退。 | M5 |
| 全站附件库、仪表盘上传 | 建索引、引用关系和清理规则，再做上传、检索、复用。 | v1.5 媒体库 |
| 评论与审核 | 静态站点先决定是否接外部评论组件；Kite 自存评论与审核需要动态存储或插件。 | 集成方案待定；自存 M7/M8 |
| 多用户、可见性、备份 | 角色、私密内容、备份/恢复一起设计，避免在文件模式做假的权限。 | M7 |
| 插件与更新提示 | 依赖插件运行时、权限模型和版本发现。 | M8 |
| 存储空间、版本更新提示 | 可以独立提供真实统计/版本查询；说明统计范围与网络失败状态。 | 可单独排 P2 |
| 访问量与 RSS 订阅数 | 静态站点需先选分析服务或服务端计数；RSS 订阅者总数通常不能精确获得。确定数据来源前不显示。 | 待定 |

## 5. 推荐实施顺序与完成口径

1. 先用可重复测试确认 A01、A05，再修复写作数据与会话恢复风险；同时补 A02、A03 的数据保护设计。
2. 完成 A04、A06–A08，让只读、失败、冲突和手机预览都能走通。
3. 完成 B01、B02、B05，使上传文件可管理、列表状态可恢复、主流程有回归保护。
4. 按里程碑做 B03、B04、B06 和占位功能；每交付一项，同步更新 [roadmap.md](roadmap.md) 与用户文档。

一项功能只有在真实页面可操作、失败与空状态明确、必要的 API/浏览器测试通过后才算完成。A01–A03 已在隔离站点验证；A05 等风险仍需复现测试来最终定性。
